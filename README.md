# ChaosGUI-Pack

Resource-Pack des ChaosGUI-Plugins (Menü-Designs für den ChaosCraft-Server, Minecraft 26.3).
Wird vom Server automatisch beim Beitritt angeboten, nicht manuell installieren.

Direktlink (für `pack.url` in `plugins/ChaosGUI/config.yml`):

    https://raw.githubusercontent.com/Schuhfinn55/chaosgui-pack/main/ChaosGUI-pack.zip

SHA-1 steht in `ChaosGUI-pack.zip.sha1`. Quelle: Generator `tools/build_pack.py` im ChaosGUI-Projekt.
